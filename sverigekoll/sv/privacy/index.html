Översikt

Sverigekoll är en studieapp inför medborgarskapsprovet. Appen kräver inget konto och innehåller ingen reklam, ingen analys, ingen kraschrapportering och ingen spårning.

Det som sparas på din enhet

Dina svar, kapitelframsteg, provhistorik, misstagslista och inställningar sparas endast på din enhet. De skickas inte till någon server som utvecklaren driver. Om du raderar appen försvinner dessa uppgifter.

Det som inte samlas in

Sverigekoll frågar inte efter ditt namn, din e-postadress, ditt telefonnummer, din plats eller dina kontakter. Appen läser inte dina bilder, filer eller din kalender. Den bygger ingen profil av dig och följer dig inte i andra appar eller på webbplatser.

Användning av nätverket

Läsmaterialet och frågorna ligger inuti appen, så studierna fungerar utan uppkoppling. Appen använder nätverket endast via Apples egen StoreKit-tjänst när du öppnar köpvyn, köper eller återställer ett köp.

Köp

Det frivilliga engångsköpet som låser upp alla kapitel hanteras av Apple via StoreKit. Sverigekoll kontrollerar köpet på din enhet och tar aldrig emot eller lagrar dina kortuppgifter. Apple hanterar transaktioner i App Store enligt Apples egna villkor.

Att rapportera ett fel

Om du använder rapportknappen i appen öppnar iOS ditt eget e-postprogram med ett meddelande adresserat till utvecklaren. Ingenting skickas förrän du trycker på skicka, och du bestämmer vad meddelandet innehåller. E-post som skickas på detta sätt används endast för att svara dig och för att rätta det innehåll du rapporterat.

Barn

Sverigekoll är ett studieverktyg inför ett prov för vuxna. Appen riktar sig inte till barn och samlar inte in personuppgifter från någon.

Dina val

  • Nollställ dina framsteg i appens egna inställningar där det är möjligt.
  • Radera Sverigekoll för att ta bort allt som appen sparat på din enhet.
  • Hantera köpet eller begär återbetalning via ditt Apple-konto.

Ändringar

Policyn kan uppdateras när Sverigekolls funktioner eller datahantering ändras. Datumet ovan anger vilken version som gäller.
